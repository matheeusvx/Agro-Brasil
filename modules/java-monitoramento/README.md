# Monitoramento territorial local — Java

Módulo acadêmico independente, ainda sem implementação. Java/Javac 21.0.10 disponíveis. Não exige API REST nem deve depender do Node.js para executar.

Escopo planejado: comunidade rural/sistema coletivo de água com leituras explicitamente simuladas; classe abstrata e polimorfismo; interface Sensor com três implementações; duas estratégias de previsão; exceções personalizadas; JDBC ou Spring Data JPA; padrão criacional; pelo menos cinco testes JUnit incluindo Mockito; menu console, alertas e reflexão crítica.

Preferir JDBC e estrutura simples, salvo justificativa para Spring. Selecionar Maven/Gradle e banco local apenas na implementação. Não há dados reais de sensores nem evidência de disponibilidade de irrigação nesta versão.
