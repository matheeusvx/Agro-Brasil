## Síntese recomendada

**Uma identidade própria, não uma colagem.** Escolher UMA linguagem principal: ilustração editorial agrícola 2D, arredondada, orgânica, com verdes naturais e céu luminoso; empregar pequenos recursos de volume/isometria apenas para ícones especiais/empty states, quando realmente ajudarem. Se a mistura 2D + 3D ficar inconsistente, preferir 2D consistente.

A tela mais importante é a do pequeno produtor: em 3–5 segundos entender propriedade, clima local e qual é a próxima ação. O app precisa continuar servindo cooperativas, instituições e compradores locais por meio de vistas próprias com o mesmo sistema visual.

## Restrições de propriedade intelectual

Não reproduzir fielmente personagens, marcas, layouts fechados, screenshots ou objetos isolados das referências. Não usar diretamente PNGs fornecidos em widgets Flutter. Produzir ilustrações e ícones originais/licenciados, documentando autoria e licenças. Este diretório ignora imagens pelo Git justamente para evitar redistribuição não autorizada em um repositório público.
